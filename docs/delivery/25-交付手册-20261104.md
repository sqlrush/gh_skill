# 交付手册：skills-v12.25（2026-11-04）

本手册覆盖从 `skills-v12.24` 到本次的全部动作。容器版同一批改动的版本号是 `agent-v1.4.6`。
诊断脚本与白名单都没有变化。

## 0. 必做与按需一览

| # | 动作 | 谁做 | 见 |
|---|---|---|---|
| 1 | 装新包（`--project /workspace`，与上一次相同；**这次会更新 `/workspace/AGENTS.md`**，旧的自动备份） | 平台 | 第 2 节 |

**不用做**：白名单（不变，仍是 128 条）、环境变量、已有的知识库文件（不用改、不用重建索引）。

## 1. 本次交付物与变更

| 项 | 说明 |
|---|---|
| skill 包 | `gaussdb-skills-<提交号>-20261104.tar.gz`，对应标签 `skills-v12.25` |
| 白名单 | 不变（128 条） |

版本号：各 skill 不变（只改认定规则、措辞与注入的公共段落）。

- **Top SQL 只列业务 SQL**（慢 SQL、健康检查、WDR 的 SQL 榜同一口径）。以下四类一律排除，报告只说按类排除了几条，不列正文：
  内核与数据字典（查系统表 / 系统视图 / 系统函数，含 `ADM_*`、`DB_*`、`MY_*`、`V$*`、`DUAL` 这类没有前缀的数据字典视图，
  名单取自官方文档）；会话设置与事务控制（SET / SHOW / BEGIN / COMMIT，`select 1`、`select version()` 这类连接探活）；
  运维管理（建删库 / 用户 / 角色 / schema、GRANT / REVOKE、VACUUM / ANALYZE、EXPLAIN）；中间件自身（读写 `grmp.*` 白名单与配置表的语句、
  我方探测用的临时表）。拿不准的仍按业务 SQL 保留。不再提示「加 `--include-system` 看系统 SQL」。
- **回答里不出现系统 SQL**：安全红线新增「不写系统 SQL」；锁等待的快速恢复改为「取消该会话正在执行的语句 / 断开该会话」与 pid、sessionid；
  存储过程找不到时给 DBA 的核对与授权、中间件报错时的排查提示，都改成要做的事。
- **提示词**：「贵行」一律改为「本行」；`AGENTS.md` 里「安全红线」并入「禁止行为」（与红线重复的三条合并，原条目里多出来的说法并进红线）；
  去掉「用户说「帮我生成报告」时」一节与技能里「把大盘链接转给用户」的说法，脚本存档后也不再打报告链接（报告由前端调用）。
- 单机版 `AGENTS.md` 里根规范仍是 `/workspace/search_docs.py` 与 `/workspace/docs/`（单机环境里的真实路径）。

## 2. 安装 skill 包

```bash
tar xzf gaussdb-skills-<提交号>-20261104.tar.gz
cd gaussdb-skills-<提交号>
bash install-opencode.sh --project /workspace
```

安装时 `/workspace/AGENTS.md` 与新版不同会先备份成 `AGENTS.md.bak.<时间>` 再覆盖。贵方在 `AGENTS.md` 里自己加过内容的，
对照备份把自己加的那几段补回新文件。装完问一次「看下 Top SQL」，榜上应只有业务 SQL、末尾写着「已排除 N 条非业务 SQL」。

## 3. 回滚

`bash install-opencode.sh --rollback` 回到上一版 skill；`AGENTS.md` 用安装时留下的 `AGENTS.md.bak.<时间>` 换回。
