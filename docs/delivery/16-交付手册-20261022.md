### 相对上一版的变更摘要

**新功能**

- **时段锁回溯**（`lockwait.py --from … --to …`）：锁视图只有此刻，语句历史只记锁等待总时长；数据库自带的活跃会话采样（ASP）
  每个样本都记着当时在等哪个会话。现在可以事后回看某段时间里谁挡了谁：阻塞对、阻塞链与根、根会话的状态 / 应用 / 客户端 / 事务开始时间、
  约等了多久（采到次数 × 落表间隔，约 10 秒一个样本，是估算）。**事后回看不生成 kill 语句**（当时的会话可能已结束）。
  健康检查的时段体检终点在过去时，「锁与阻塞链」不再标「回看不了」，改由它填。
- **历史真实执行计划**（`explain.py --sql-id`）：语句历史里的文本带占位符（无法重新 EXPLAIN）或被截断时，先给语句历史里记下的
  **当时真实执行的计划**（带实际耗时与行数），并标明是哪次执行、耗时多少。
- **WDR 附录带真实计划**：WDR 采集时取根因里提到的语句在窗口内的真实执行计划，SQL 附录直接展示，不再写「执行计划：本次未取到」。

**修复**

- sqltune / explain：语句历史里的 `schema_name` 是搜索路径串（如 `fl, public`）时，按逗号拆开逐段校验并整串切换，不再报「不是合法标识符、未切换 search_path」。
- explain：文本是归一化的时，报错不再一律说「statement_history 里没有这条」（实际有，只是记的就是带占位符的文本）。
- 时段锁回溯里，根会话在采样里没出现（空闲会话持有会话级锁）时写明原因；空闲事务根会话的证据里写明「不要据此 kill」。

## 6. DBA 侧配置

数据库参数由贵方 DBA 评估后开启或调整，我方不改数据库参数。查看当前值：

```sql
SELECT name, setting FROM pg_settings
 WHERE name IN ('enable_asp', 'asp_sample_interval', 'asp_flush_rate', 'asp_retention_days',
                'track_stmt_retention_time', 'track_stmt_stat_level');
```

### 6.1 活跃会话采样（时段锁回溯的前提）

| 参数 | 默认 | 影响 |
|---|---|---|
| `enable_asp` | `on` | 采样总开关；关闭时时段锁回溯会明说「回看不了」 |
| `asp_sample_interval` × `asp_flush_rate` | 1 秒 × 10 | 约每 10 秒落一个样本：事后能看到的粒度约 10 秒，更短的锁等待可能采不到 |
| `asp_retention_days` | 2（天） | 能回看几天的锁；要回看更久按需调大 |

### 6.2 语句历史（历史真实执行计划的前提）

| 参数 | 说明 |
|---|---|
| `track_stmt_retention_time` | 格式「全量 SQL 秒数,慢 SQL 秒数」，默认 `3600,604800`。全量那一项**最大 86400**（24 小时，设 7 天会被拒）；慢 SQL 最长 7 天。全量只留 1 小时时，隔天按 sql_id 取普通语句的计划会落空 |
| `track_stmt_stat_level` | 第一项是全量 SQL 的记录级别，为 `OFF` 时不记全量 SQL，只有慢 SQL 有历史计划 |

保留期调大会占存储（我方测试库全量记录 20 分钟约 146 万条），请按存储余量评估。

## 7. 安装后冒烟

在贵方沙箱里依次跑，`<句柄>` 是登录输出的那一串，时间按数据库所在时区。

| # | 命令 | 期望 |
|---|---|---|
| 1 | `login.py --ip <实例> --database <库>` | 输出会话句柄；中间件应答正常 |
| 2 | `lockwait.py --session <句柄> --from '<近一小时的开始>' --to '<结束>'` | 抬头「# 时段锁回溯」，来源一行写明「活跃会话采样，… 个样本」；没有锁等待时明说「时段内没有采到锁等待」 |

| 4 | `explain.py --session <句柄> --sql-id <一条带参数的语句的 sql_id>` | 来源一行写「SQL 历史里记下的真实执行计划（… 那次执行 …）」；语句历史里没有计划时给出原因与改用 sqltune 的指路 |
| 5 | `sqltune.py --session <句柄> <schema_name 为 'a, public' 形式的 sql_id>` | 写「search_path 已切到 `a, public`」，不再报不是合法标识符 |
