### 相对上一版的变更摘要

**新功能**

- **内网网页导入（网页剪藏）**：需要登录的 Wiki / Confluence / 门户页面，服务端抓不到（带不上用户浏览器的登录状态），
  由知识库管理员在**已登录的浏览器**里把页面带进来，模型不访问任何网址。
  - 容器版：管理员在页面上点书签「导入知识库」即可，第一次由模型一步一步带着装书签（见容器版《版本说明》）。
  - 单机版（本包）：浏览器「另存为 → 网页，单个文件（.mhtml）」，上传到收件目录后由模型执行 `kb.py clip add <文件>`。
  - 之后同一条路：`kb.py clip ingest` 把网页转成干净的 md（找正文，去掉导航、侧栏、评论、页脚，保留标题层级、表格、代码与页内截图），
    模型判断材料类型后走现有流程——故障记录 / 事件复盘按六要素标准化成案例，规范条款化，手册、缺陷、基线、Wiki 等按八类模板写条目；
    筛掉与数据库运维无关的段落，写入前照常给管理员确认清单。原始网页挂成 L3 证据，出处记原网页地址；同一网页再次导入且内容变了，
    提示按新版更新已入库的条目。剪到登录页、无权限页、空白页时拒绝并说明，不把「请登录」当成知识入库。
- **扫描件 PDF 看图转录**：以前没有文字层的 PDF 直接拒绝；现在每页渲染成图片（默认最多 30 页，`KB_PDF_MAX_PAGES` 可调，1–200），
  由模型逐页看图转录（保留章节、条款编号与表格；看不清的写「[看不清]」并集中问管理员，不猜），转录完再条款化或标准化。
  没转录完的稿子 `kb.py validate` 会提示，不会被当成空规范导入。
- **PPT（.pptx）导入**：按放映顺序抽每页的标题、分级要点、表格与演讲者备注；幻灯片里的图片取出来，需要时由模型看图补充。
  老格式 `.ppt`（以及 `.xls`、`.rtf`、WPS 的 `.et` / `.wps` / `.dps`）提示另存为什么格式再传。

## 3. 知识库导入的新用法（知识库管理员）

### 3.1 内网网页

对模型说「导入这个网页 `<链接>`」即可，模型会按 skill 的「网页剪藏」一节引导。单机版的步骤是：

1. 在已登录的浏览器里打开要导入的页面，等加载完，按 **Ctrl+S**（Mac **Cmd+S**），保存类型选「网页，单个文件（*.mhtml）」。
2. 通过对话界面把 .mhtml 上传到收件目录（`kb.py health` 的「收件目录」行）。
3. 模型执行 `kb.py clip add <沙箱内路径>`（文件里没记原网页地址时加 `--url <地址>`）→ `kb.py clip ingest` → 按材料类型整理 → 给确认清单。

不要把 Wiki 的 cookie、口令或令牌发给模型。

### 3.2 扫描件 PDF 与 PPT

和以前一样上传后说「导入这份规范 / 这些材料」。扫描件需要：

- 导入环境有 `pdftoppm`：`pdftoppm -v` 能输出版本即可；没有时装 `poppler-utils`（导文字版 PDF 的 `pdftotext` 出自同一个包）。
  没有时导扫描件会明确报「缺 pdftoppm（poppler）」，不会静默跳过。
- 模型服务支持图片输入（与读照片工单同一个前提）；不支持时模型会说明读不了图片，请管理员先做 OCR。
