# 交付手册：skills-v12.24（2026-11-04）

本手册覆盖从 `skills-v12.23` 到本次的全部动作。容器版同一批改动的版本号是 `agent-v1.4.5`。
本次只改提示词：检索顺序、根规范的引用写法、措辞统一；诊断脚本与白名单都没有变化。

## 0. 必做与按需一览

| # | 动作 | 谁做 | 见 |
|---|---|---|---|
| 1 | 装新包（`--project /workspace`，与上一次相同；**这次会更新 `/workspace/AGENTS.md`**，旧的自动备份） | 平台 | 第 2 节 |
| 2 | （按需）根规范放进 `/workspace/docs/` | 平台 / 规范管理员 | 第 1 节 |

**不用做**：白名单（不变，仍是 128 条）、环境变量、已有的知识库文件（不用改、不用重建索引）。

## 1. 本次交付物与变更

| 项 | 说明 |
|---|---|
| skill 包 | `gaussdb-skills-<提交号>-20261104.tar.gz`，对应标签 `skills-v12.24` |
| 白名单 | 不变（128 条） |

版本号：各 skill 不变（只改措辞与注入的公共段落）。

- **检索顺序**：`AGENTS.md` 写明 **本行知识库 → 根规范（`/workspace/docs/`）→ 模型自带知识**。先用 `gaussdb-kb` 查本行知识库
  （诊断类问题由诊断 skill 的输出自带）；知识库不可用或查不到时，用 `python3 /workspace/search_docs.py "关键词"` 检索 `/workspace/docs/` 里的规范；
  两处都没有才用通用知识，并标注「知识库中未找到相关内容，以下为通用知识，仅供参考」。`/workspace/docs/` 里第一行带 `ROOTSPEC-TEMPLATE`
  标记的是模板，不得引用。
- **根规范的引用写法**：出自根规范的句子与知识库条目一样上色，括号写「引用自《文档名称》第X章/X节」；知识问答的「解答来源」写
  「《文档名称》第X章/X节」。写法在 `AGENTS.md`、`gaussdb-kb` 与 9 个做判断的 skill 的知识库契约里是同一段原文。
- **措辞**：提示词、skill 说明与脚本输出里不再用「客户」指代行方，改为本行 / 行方 / 行内；「客户端」「客户表」等业务与技术用语不变。
  `AGENTS.md` 去掉了版本号、日期批注与改动标记（`▼▼▼ … ▲▲▲`）。
- **安全红线**的示例补上知识库导入环境的说法（容器版两种环境各有一份根提示词；单机版两种技能都装，照常可用）。

## 2. 安装 skill 包

```bash
tar xzf gaussdb-skills-<提交号>-20261104.tar.gz
cd gaussdb-skills-<提交号>
bash install-opencode.sh --project /workspace
```

安装时 `/workspace/AGENTS.md` 与新版不同会先备份成 `AGENTS.md.bak.<时间>` 再覆盖。贵方在 `AGENTS.md` 里自己加过内容的，
对照备份把自己加的那几段补回新文件。装完问一个只在根规范里写了的问题，回答里应引用「《文档名称》第X章/X节」。

## 3. 回滚

`bash install-opencode.sh --rollback` 回到上一版 skill；`AGENTS.md` 用安装时留下的 `AGENTS.md.bak.<时间>` 换回。
