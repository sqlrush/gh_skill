本手册覆盖从 `skills-v12.20` 到本次的全部动作。容器版同一批改动的版本号是 `agent-v1.4.2`。
本次只有一处技能脚本改动，配合「GaussDB 官方文档集作为标准知识库随版本发布、部署后自动装上」。

## 0. 必做与按需一览

| # | 动作 | 谁做 | 见 |

## 1. 本次交付物与变更

| 项 | 说明 |

  不该每次都重写客户知识库的总索引与专题导航。装上新版本时照旧重建。

## 2. 安装 skill 包

```bash
tar xzf gaussdb-skills-<提交号>-20261027.tar.gz
cd gaussdb-skills-<提交号>
bash install-opencode.sh --project /workspace
```

## 3. 装标准知识库包（单机版，按需）

容器版部署时由 Job 自动装上，不用手工做。单机版要用同一套官方文档时，从标准知识库镜像里取出包再装：

```bash
docker create --name kbstd <镜像仓>/gaussdb-agent-kbstd:agent-v1.4.2-oc1.18.27
docker cp kbstd:/kbstd/. ./kbstd-packs/ && docker rm kbstd
python3 /workspace/.opencode/skills/gaussdb-kb/scripts/kb.py docset install ./kbstd-packs
```

**期望**：`[installed] G25132C 已装上:… · 6023 条 · …` 与 `分层 : L0 / L1 已按装好的文档集重建`；再装一次是 `[skipped] … 已是这个版本`。
装之前逐个文件核对 sha256，对不上就不换；只动知识库的 `docsets/<代号>/`，贵方自己的规范、案例、条目不碰。

## 4. 回滚

`bash install-opencode.sh --rollback`。已装的官方文档集旧版 skill 照常能读；要卸掉整套用 `kb.py docset retire G25132C`。
